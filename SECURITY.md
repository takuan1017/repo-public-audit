# Security Policy

## Reporting a Vulnerability

Please report security issues by opening a private security advisory on GitHub if available.

If that is not available, open an issue with a minimal description and avoid posting secrets, tokens, private repository contents, or sensitive file snippets.

## Scanner Guarantees

`repo-public-audit` is a local scanner. It should not send repository contents to external services.

A clean result does not guarantee that a repository is safe to publish. Always review Git history and rotate any credential that may have been committed.
